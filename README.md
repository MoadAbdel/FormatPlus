# Projet apprenant — TP n°3

## Objectif

Optimiser l’assistant métier construit pendant le TP n°2.

Vous devez travailler sur :

- les tests ;
- les erreurs observées ;
- le prompt système ;
- le format des réponses ;
- les limites ;
- l’incertitude ;
- la température.

## Lancement

```bash
npm install
npm run dev
```

Ouvrez ensuite :

```text
http://localhost:3000
```

Dupliquez `.env.example` et renommez la copie `.env`.
